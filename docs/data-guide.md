# 数据准备教程

交叉验证需要四个体系的命盘数据。**推荐用爱占星一次性导出全部四个盘。**

> 为什么不能用出生时间自动排盘？因为 AI 没有星历表，无法计算行星黄经和紫微安星。用软件导出命盘是唯一可靠的数据来源。

---

## 方法一：爱占星（推荐，一个 App 四个盘）

[爱占星](https://www.aizhanxing.com/) 支持八字、紫微斗数、印度占星、现代占星，一次设置出生资料即可导出全部。

### 步骤

1. **下载并安装爱占星**
2. **添加命主资料**：输入出生日期、时间、地点、性别
3. **依次导出四个命盘**：

| 体系 | 在 App 中的入口 | 导出方式 |
|------|----------------|----------|
| 八字 | 「八字」标签页 | 截图或复制排盘文本 |
| 紫微斗数 | 「紫微」标签页 | 截图或复制十二宫文本 |
| 印度占星 | 「印占」标签页 | 截图或复制星盘数据 |
| 现代占星 | 「占星」标签页 | 截图或复制星盘数据 |

4. **保存文件**：将四个命盘分别保存到项目目录下，例如：

```
charts/steve-jobs/
├── bazi.txt
├── ziwei.txt
├── vedic.txt
└── modern.txt
```

5. **在 Claude Code 中引用**：启动 `/cross-check` 后，回复 `方式A，文件在 charts/steve-jobs/ 目录下`

## 数据门槛

系统会对命盘数据做基本校验。如果数据格式不符合要求，对应体系会被跳过：

| 体系 | 最低要求 |
|------|----------|
| 八字 | 文本中包含至少 4 组天干地支组合，或标注了年柱/月柱/日柱 |
| 紫微 | 文本中包含至少 8 个十二宫名称（命宫/兄弟/夫妻…） |
| 印度占星 | 文本中包含上升/ASC/Lagna + 度数标记（°） + D-1/Rasi/Ayanamsa |
| 现代占星 | 文本中包含 ASC/上升 + 度数标记（°） + 日月行星名称 |

> 如果数据门槛未通过，系统会明确告知缺少什么，并自动跳过该体系。

## 常见数据问题

### 八字缺时辰

只能分析前三柱（年柱、月柱、日柱）。时柱、子女、晚景和精确应期无法输出。

### 没提供大运/起运数据

八字和紫微的大运/大限分析会被限制。八字只能做原局结构性分析，不能出具体年份窗口。

### 没有行运数据（现代占星）

系统不会估算当前行星位置。如果需要行运分析，请在软件中额外导出指定日期的 Transit/行运盘。

### 缺性别

八字大运根据性别分顺排/逆排。缺性别时大运方向无法确定，时间分析降信度。
