# 紫微斗数分析

## 开始前

1. 回显排盘来源、历法口径、出生时间地点、性别、命身宫、五行局、生年四化和大限状态。
2. 用户确认后再分析。
3. 不用语言模型从出生资料重建十二宫和星曜。命宫、五行局、紫微星是级联计算，上游错误会改变全盘——以可靠软件盘为准，不在 Skill 中内置简化安星公式。

## 数据门槛

- 正式分析必须有完整十二宫软件盘：宫位、宫干、主星、辅煞星、庙旺落陷和生年四化。
- 钦天/飞星分析还需离心/向心自化数据。
- 时间分析必须有大限、流年盘或对应四化数据。
- 缺时辰或完整盘时停止正式断盘，只说明需要补充什么。

## 路由

- 快速问题：读取 [references/workflow-standard.md](references/workflow-standard.md)，只回答用户指定维度。
- 标准报告：读取同一文件，覆盖核心结构、指定维度、限制和可用时间数据。
- 深度报告：再读取 [references/workflow-deep.md](references/workflow-deep.md)，展开三合/钦天/飞星/河洛多学派推理。

## Decision Cues（用户意图 → 分析重点）

当用户说以下内容时，调整分析权重：

- "看看事业/工作" → 重点：官禄宫+身宫+来因宫、命宫三方四正的事业指向、飞星忌入官禄
- "婚姻/感情" → 重点：夫妻宫+三方（迁移+福德+官禄）、红鸾天喜、飞星忌入夫妻
- "财运/赚钱" → 重点：财帛宫+田宅宫、禄星落宫+自化禄、串联中的财星
- "健康/身体" → 重点：疾厄宫+命宫煞星、忌星是否入疾厄
- "跟父母/原生家庭" → 重点：父母宫+命宫、四化入父母宫的互动
- "适合出去发展吗" → 重点：迁移宫+命宫对宫互冲、大限迁移
- "最近运势/今年" → 重点：当前大限宫位+流年四化+流年命宫三方

## 输出规则

- 三合派按本宫、对宫、三合宫与夹宫组织证据；权重数字（如 40%/30%/15%）是项目启发式，非传统统一定量标准。
- 生年四化、自化、宫干飞化分别标注，不互相替代。
- 串联必须把使用的学派定义、方向、象和参与宫位写清楚；资料不足就不串联。
- 空宫写明借宫规则和限制（借对宫星曜不借地），不把"空"解释成没有事件。
- 每个结论标注学派、盘面依据、数据质量和证据强度。

## 禁止

- 不引入八字、印占或现代占星术语。
- 不使用"业力""注定"等词替代可检查的宫星关系。
- 不根据单宫、单星或单个化忌直接推导重大事件。
- 不输出无大限/流年数据支持的具体时间窗口。

## 常见错误（Gotchas —— 从真实失败中沉淀，优先级最高）

1. **只看单宫不综合** — 盯着命宫放一堆星星就说性格，没看三方四正。正确：每宫按本宫+对宫+两个三合宫综合判断。

2. **空宫不敢借星** — 空宫跳过不分析。正确：空宫更需要借对宫星曜，只是庙旺以对宫地支为准（借星不借地）。

3. **串联随便连** — 同象自化都串在一起，不检查方向和阻断。正确：串联四条件（同向+同象+至少两宫+只串宫不串星）缺一不可；串完必须法象生年四化；检查逢三则变、反背、生年象阻断。

4. **逢三则变没识别** — 三宫同象同向，中间宫位会断开，不能整串→结论全错。

5. **忌星追踪半途而废** — 飞星忌星只看一次飞渡就停。正确：忌星所落之处 = 业力终端，必须追到底（忌转忌二次飞渡）。

## 质量自检

- [ ] 命盘是否来自专业软件（非自排）？
- [ ] 三合派不是只看单宫——每宫都看了三方四正？
- [ ] 空宫是否正确借星了？
- [ ] 自化串联是否满足了同向+同象+至少两宫三条件？
- [ ] 串联是否做了法象？是否检查了阻断？
- [ ] 飞星忌星是否追踪了二次飞渡？
- [ ] 有没有引入紫微体系外的术语？
