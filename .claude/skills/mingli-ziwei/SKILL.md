# 紫微斗数分析

## 开始前

1. 回显排盘来源、历法口径、出生时间地点、性别、命身宫、五行局、生年四化和大限状态。
2. 用户确认后再分析。
3. 不用语言模型从出生资料重建十二宫和星曜。命宫→五行局→紫微星是级联计算，任何上游错误都会改变全盘——以可靠软件盘为准。

## 数据输入方式

### 方式一：排盘软件导出（推荐）

推荐软件：
- **爱占星**（全体系通用，一个 App 出四个盘）
- **文墨天机**（紫微专用，安星精准、流派支持全）
- **测测**（全体系通用，网页版也可用）

用户可保存到项目目录并告知文件名，或直接粘贴十二宫排盘文本。排盘应包含：十二宫名称、宫干、主星、辅煞星、庙旺落陷、生年四化、命身宫、五行局、来因宫。

### 方式二：只给出生时间（仅辅助校验，不进入正式断盘）

```
出生时间: YYYY-MM-DD HH:MM
出生地点: 省-市
性别: 男/女
```
不生成完整命盘，不进入正式十二宫分析。请先用专业软件导出。

## 数据门槛

- 正式分析必须有完整十二宫软件盘：宫位、宫干、主星、辅煞星、庙旺落陷和生年四化。
- 钦天/飞星分析还需：离心/向心自化数据。
- 时间分析必须有大限、流年盘或对应四化数据。
- 缺时辰或完整十二宫盘时停止正式断盘，只说明需要补充什么。

## 数据异常处理

- **缺出生时辰**：命宫无法确定，停止正式紫微分析。不以降信度的方式继续断盘。
- **缺完整十二宫**：只做基础校验（命宫/五行局/生年四化），不进入全盘分析。
- **缺大限/流年数据**：只做本命盘结构性分析，不输出时间窗口。
- **排盘不确定**：五行局、紫微星定位、十四主星安星——三者任一不确定 → 整盘标「待人工校验」。

## 路由

- 快速问题：读取 [references/workflow-standard.md](references/workflow-standard.md)，只回答用户指定维度。
- 标准报告：读取同一文件，覆盖核心结构、指定维度、限制和可用时间数据。

## Decision Cues（用户意图 → 分析重点）

- "看看事业/工作" → 重点：官禄宫+身宫+来因宫、命宫三方四正的事业指向、飞星忌入官禄
- "婚姻/感情" → 重点：夫妻宫+三方（迁移+福德+官禄）、红鸾天喜、飞星忌入夫妻
- "财运/赚钱" → 重点：财帛宫+田宅宫、禄星落宫+自化禄、串联中的财星
- "健康/身体" → 重点：疾厄宫+命宫煞星、忌星是否入疾厄
- "跟父母/原生家庭" → 重点：父母宫+命宫、四化入父母宫的互动
- "适合出去发展吗" → 重点：迁移宫+命宫对宫互冲、大限迁移
- "最近运势/今年" → 重点：当前大限宫位+流年四化+流年命宫三方
- "性格/我是什么样的人" → 重点：命宫+福德宫+身宫的星群组合

## 输出规则

- 正文必须先给“十二宫地图与推导过程”，再进入用户指定维度。依次解释：命身与命财官 → 各相关宫位的本宫/对宫/三合 → 生年四化 → 自化/飞化 → 大限流年；不得只列星曜关键词。
- 每个关键结论使用三层链：原始盘面 → 对应解释（派别规则、宫位关系、四化路径、竞争解释）→ 得出结论（中间机制、条件、反证与边界）。
- 三合派按本宫、对宫、三合宫与夹宫组织证据。权重数字（如 40%/30%/15%）是项目启发式——中州派用等级排序，另有讲义给不同比例。《紫微斗数全书》无定量规定。正式报告用证据排序，不输出伪精确百分比。
- 空宫写明借宫规则和限制（借对宫星曜不借地），不把“空”解释成没有事件，不输出无统一经典依据的固定强度百分比。
- 生年四化、自化、宫干飞化分别标注，不互相替代。
- 串联必须把使用的学派定义、方向、象和参与宫位写清楚；资料不足就不串联。不同传承对串联存在差异时保留原软件口径。
- 忌表示该宫位的执着、压力、欠缺感或较高错误成本；必须结合星曜、宫位、飞化路径与反证，不把忌当作“业力终端”。
- 离心自化只说明该象有向外、变化、不易固守或关系重新分配的倾向；“去中心化领导力”“不适合层级组织”等属于后续现实翻译，必须另有命身官迁财等证据支持。
- 回答现实选择题时，先把选项拆成可观察条件，再由相关宫位、三方四正和四化路径分别寻找支持与反证；单宫、单星、单一自化不能决定现实选项。
- 每个结论标注学派、盘面依据、数据质量和证据强度。

## 禁止

- 不引入八字、印占或现代占星术语。
- 不使用"业力""注定"等词替代可检查的宫星关系。
- 不根据单宫、单星或单个化忌直接推导重大事件。
- 不输出无大限/流年数据支持的具体时间窗口。
- 不使用"确定""必然"描述未来事件。

## 常见错误（Gotchas —— 从真实失败中沉淀，优先级最高）

1. **只看单宫不综合** — 盯着命宫放一堆星星就说性格，没看三方四正。正确：每宫按本宫+对宫+两个三合宫综合判断。

2. **空宫不敢借星** — 空宫跳过不分析。正确：空宫更需要借对宫星曜，只是庙旺以对宫地支为准（借星不借地）。

3. **串联随便连** — 同象自化都串在一起，不检查方向和阻断。串联四条件（同向+同象+至少两宫+只串宫不串星）缺一不可；串完必须法象生年四化；检查逢三则变、反背、生年象阻断。

4. **逢三则变没识别** — 三宫同象同向，中间宫位会断开，不能整串→结论全错。

5. **忌星追踪半途而废** — 飞星忌星只看一次飞渡就停。正确：在所声明的飞星口径中继续检查忌转忌等后续路径，同时观察落宫的压力、执着或错误成本；不把路径终点写成可证实的“业力终端”。

6. **来因宫被忽略** — 来因宫（生年天干所在宫位）解读优先级高于普通宫位——它是今生气运的起点场域。分析时先看来因宫。

7. **自化被直接翻译成现实标签** — 自化首先描述该宫之象如何变化，不直接等于某种职业、关系结果或人生事件。先解释作用路径，再与相关宫位和现实问题条件综合。

## 质量自检

- [ ] 命盘是否来自专业软件（非自排）？
- [ ] 三合派每宫都看了三方四正？（非只看单宫）
- [ ] 空宫是否正确借星了？（借星不借地）
- [ ] 自化串联是否满足了四条件？是否法象？是否检查阻断？
- [ ] 飞星忌星是否追踪了二次飞渡？
- [ ] 来因宫是否优先解读了？
- [ ] 三方四正权重只说排序不报伪精确百分比？
- [ ] 是否把忌写成可检查的压力/成本，而非“业力终端”？
- [ ] 现实结论是否由相关宫位组合得出，而非单一自化？
- [ ] 有没有引入紫微体系外的术语？
