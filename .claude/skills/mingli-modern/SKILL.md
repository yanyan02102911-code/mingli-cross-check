# 现代占星分析

## 开始前

1. 回显热带/恒星口径、宫制（默认 Whole Sign）、ASC、MC、行星度数、相位表、交点口径（真交点/平均交点）和数据来源。
2. 用户软件使用不同宫制时先确认是否保持原盘口径。
3. 用户确认后再分析。性别不是现代占星必需输入。

## 数据输入方式

### 方式一：排盘软件导出（强烈推荐）

推荐软件：
- **爱占星**（全体系通用，一个 App 出四个盘）
- **astro.com**（最权威的免费在线星盘，英文界面）
- **AstroGold** / **TimePassages**（App，专业占星师常用）

⚠️ 现代占星需要精确的行星黄经度数。Agent 没有星历表，**无法自行排盘**。

用户可保存到项目目录并告知文件名，或直接粘贴星盘文本。排盘应包含：ASC/MC 度数、各行星黄经度数+星座+宫位、相位表（含 orb）、南北交点位置。

**行运数据需单独提供**：如需行运分析，请额外导出指定日期的 Transit/行运盘。

### 方式二：只给出生时间（不进入完整本命盘分析）

```
出生时间: YYYY-MM-DD HH:MM
出生地点: 省-市
性别: 男/女
```
Agent 不估算 ASC、月亮、宫位或相位。如用户只问太阳星座的一般象征，可作有限的太阳主题解读，但必须明确说明这不是完整本命盘分析。

## 数据门槛

- **完整本命盘**：需要行星黄经、ASC 和出生时间。缺出生时间时只做无宫位、无角度点的有限分析。
- **相位**：需要精确度数或软件相位表，并声明 orb（容许度）范围。
- **行运（Transit）**：除本命盘外，还必须有指定日期的 transit 行星度数或软件行运表。Agent 没有实时星历，**无法自行计算当前行星位置**。
- 只有本命盘时，不输出当前行运位置、精确生效日期或 applying/separating 状态。标注"未进行行运分析——无行运数据"。

## 数据异常处理

- **缺出生分钟且无已排星盘**：不估算 ASC 和宫位，停止完整本命盘分析。
- **缺出生地点且无已排星盘**：不使用默认地点代替，请用户补充。
- **缺性别**：不影响分析——现代占星不依赖性别差异。标注"未获取性别信息"。
- **行运数据缺失**：只做本命盘分析，行运章节跳过。禁止凭记忆填写"当前土星在某座"。

## 路由

- 快速问题：读取 [references/workflow-standard.md](references/workflow-standard.md)，只回答用户指定维度。
- 标准报告：读取同一文件，覆盖核心结构、指定维度、限制和可用时间数据。
- 深度报告：再读取 [references/workflow-deep.md](references/workflow-deep.md)，展开相位格局/交点/行运完整推理。

## Decision Cues（用户意图 → 分析重点）

- "看看事业/工作" → 重点：MC+10宫+6宫+土星+火星、T三角中涉及10宫的顶点
- "感情/婚姻" → 重点：金星+火星+7宫+月亮-金星相位、7宫主星+行运触发（如有行运数据）
- "我是什么样的人/性格" → 重点：日月升动力三角+元素模式统计+支配行星
- "人生方向/使命" → 重点：南北交点+与交点相位的行星+T三角顶点
- "跟父母/家庭关系" → 重点：4宫+IC+月亮+土星+冥王星与4宫的相位
- "财运" → 重点：2宫+8宫+木星+太阳-木星相位
- "最近在经历什么/当前运势" → 重点：行运土星+行运木星的宫位触发（需行运数据）
- "内心的卡点/为什么总是重复" → 重点：T三角顶点+南交点+硬相位的心理动力学

## 输出规则

- 采用"行星功能 → 星座表达 → 宫位场域 → 相位互动"四层整合，避免字典式单点解释（禁止"火星在3宫=说话快"）。
- 日、月、上升分别描述意志、情绪需求和进入世界的方式，再写三者之间的和谐与张力。
- 相位强度按实际 orb（<3°极强、3-6°强、6-8°有效、>8°忽略）评估。不同学派 orb 范围存在差异——采用用户软件或声明口径。
- T 三角：顶点行星的星座+宫位=核心成长张力。补偿点在顶点的对宫位置——不要把对分两星的任一端误称为释放点。
- 交点和进化语言写成象征框架，不把前世叙事当作可证事实。所有进化占星语言标注"不可验证的象征表达"。
- 每个结论标注行星+星座+宫位+相位依据、数据质量和证据强度。

## 禁止

- 不引入八字、紫微或吠陀术语。
- 不把困难相位等同灾难（四分相是成长动力，对分相是需要整合的拉扯）。
- 不根据一个配置诊断创伤、依恋类型或精神疾病。
- 不用"命中注定""灵魂使命确定是"等绝对措辞。
- 不估算当前行运位置。

## 常见错误（Gotchas —— 从真实失败中沉淀，优先级最高）

1. **字典式单星解读** — "火星在3宫=说话快""金星在天蝎=占有欲强"。脱离行星×星座×宫位×相位整合=无效。每条必须整合四层并说明"为什么"。

2. **只分析太阳星座** — 讲了半天太阳忘了月亮和上升。日月升三角必须全部覆盖，缺一不可。

3. **硬编码模板结论** — 把一个命盘的结论套到另一个命盘。每个分析必须基于输入数据从头推导。

4. **T三角被忽略** — 找到大三角就高兴地说"天赋流畅"，但 T三角才可能是核心成长张力。被两颗星同时四分的顶点行星=全盘最重要的解盘钥匙。

5. **南北交点走过场** — "南交舒适、北交成长"然后不深入。交点的价值在于与具体行星的相位——它们揭示了具体的业力故事线索，不是抽象的"舒适区 vs 挑战区"。

6. **行运数据缺失时强行分析** — 没有 transit 数据就凭记忆说"当前土星在某座"。Agent 没有实时星历——无数据时明确跳过行运章节。

7. **宫制混淆** — Placidus 和 Whole Sign 下行运切换时间不同、宫位可能不同。标注分析的宫制，不混用。

## 质量自检

- [ ] 元素和模式统计是否基于个人行星（日月水金火）+ ASC + MC？
- [ ] 太阳/月亮/ASC 的分析是否都整合了行星-星座-宫位-相位？
- [ ] 相位解读不是孤立的两星对比——是否考虑了各自的宫位和星座？
- [ ] 南北交点的解读是否超越了"舒适区 vs 挑战区"？
- [ ] T三角的顶点是否被正确识别并重点解读？
- [ ] 行运数据缺失时是否明确标注并跳过？（不凭记忆估算）
- [ ] 宫制是否标注？有无混用？
- [ ] 有没有引入其他体系的术语？
