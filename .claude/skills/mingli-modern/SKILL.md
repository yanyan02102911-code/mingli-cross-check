# 现代占星分析

## 开始前

1. 回显热带/恒星口径、宫制、ASC、MC、行星度数、相位表、交点口径和数据来源。
2. 本项目默认热带黄道与整宫制；用户软件不同则先确认是否保持原盘口径。
3. 用户确认后再分析。性别不是现代占星必需输入。

## 数据门槛

- 完整本命盘：需要行星黄经、ASC 和出生时间；缺出生时间时只做无宫位、无角度点的有限分析。
- 相位：需要精确度数或软件相位表，并声明球差口径。
- 行运：除本命盘外，还必须有指定日期的 transit 行星度数或软件行运表。Agent 没有实时星历，**无法自行计算当前行星位置**。
- 只有本命盘时，不输出当前行运位置、精确生效日期或 applying/separating 状态。标注"未进行行运分析——无行运数据"。

## 路由

- 快速问题：读取 [references/workflow-standard.md](references/workflow-standard.md)，只回答用户指定维度。
- 标准报告：读取同一文件，覆盖核心结构、指定维度、限制和可用时间数据。
- 深度报告：再读取 [references/workflow-deep.md](references/workflow-deep.md)，展开相位格局/交点/行运完整推理。

## Decision Cues（用户意图 → 分析重点）

当用户说以下内容时，调整分析权重：

- "看看事业/工作" → 重点：MC+10宫+6宫+土星+火星、T三角中涉及10宫的顶点
- "感情/婚姻" → 重点：金星+火星+7宫+月亮-金星相位、7宫主星+行运触发（如有行运数据）
- "我是什么样的人/性格" → 重点：日月升动力三角+元素模式统计+支配行星
- "人生方向/使命" → 重点：南北交点+与交点相位的行星+T三角顶点
- "跟父母/家庭关系" → 重点：4宫+IC+月亮+土星+冥王星与4宫的相位
- "财运" → 重点：2宫+8宫+木星+太阳-木星相位
- "最近在经历什么/当前运势" → 重点：行运土星+行运木星的宫位触发（需行运数据）
- "内心的卡点/为什么总是重复" → 重点：T三角顶点+南交点+硬相位的心理动力学

## 输出规则

- 采用"行星功能 → 星座表达 → 宫位场域 → 相位互动"的整合顺序，避免字典式单点解释。
- 日、月、上升分别描述意志、情绪需求和进入世界的方式，再写三者张力。
- 相位强度按实际球差与用户声明的 orb 评估，不把一套固定 orb 说成行业唯一标准。
- T 三角的补偿点是顶点行星的对宫位置；不要把对分两星的任一端误称为释放点。
- 交点和进化语言写成象征框架，不把前世叙事当作可证事实。
- 每个结论标注行星+星座+宫位+相位依据、数据质量和证据强度。

## 禁止

- 不引入八字、紫微或吠陀术语。
- 不把困难相位等同灾难，不根据一个配置诊断创伤或精神疾病。
- 不用"命中注定""灵魂使命确定是"等绝对措辞。

## 常见错误（Gotchas —— 从真实失败中沉淀，优先级最高）

1. **字典式单星解读** — "火星在3宫 = 说话快""金星在天蝎 = 占有欲强"。脱离行星×星座×宫位×相位整合 = 无效。每条解读必须整合四层并说明"为什么"。

2. **只分析太阳星座** — 讲了半天太阳忘了月亮和上升。日月升三角必须全部覆盖，缺一不可。

3. **硬编码模板结论** — 把一个命盘的结论套到另一个命盘。每个分析必须基于输入数据从头推导。

4. **T三角被忽略** — 找到大三角就高兴地说"天赋流畅"，但 T三角才可能是核心成长张力。被两颗星同时四分的顶点行星 = 全盘最重要的解盘钥匙。

5. **南北交点走过场** — "南交舒适、北交成长"然后不深入。交点的价值在于与具体行星的相位——它们揭示了具体的业力故事线索，不是抽象的"舒适区 vs 挑战区"。

6. **行运不被考虑** — 本命盘分析了半天不问土星木星当前在哪。但必须记住：没有行运数据时明确标注跳过行运分析，不估算。

## 质量自检

- [ ] 元素和模式统计是否基于个人行星（日月水金火）+ ASC + MC？
- [ ] 太阳/月亮/ASC 的分析是否都整合了行星-星座-宫位-相位？
- [ ] 相位解读不是孤立的两星对比——是否考虑了各自的宫位和星座？
- [ ] 南北交点的解读是否超越了"舒适区 vs 挑战区"？
- [ ] T三角的顶点是否被正确识别并重点解读？
- [ ] 行运数据缺失时是否明确标注并跳过？
- [ ] 有没有引入其他体系（八字/紫微/吠陀）的术语？
