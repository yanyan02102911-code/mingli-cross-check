# 印度占星分析

## 开始前

1. 回显黄道体系（恒星黄道/热带）、Ayanamsa（默认 Lahiri）、宫制、上升度数、行星度数、D-1/D-9、Dasha 和数据来源。
2. 明确本次采用 Parashara 主框架；使用 Jaimini Chara Karaka 时单独标注方法来源。
3. 用户确认后再分析，不从出生资料估算星历数据。

## 数据输入方式

### 方式一：排盘软件导出（强烈推荐）

推荐软件：
- **爱占星**（全体系通用，一个 App 出四个盘）
- **Jagannatha Hora**（印占专用，Windows 免费，功能最全）
- **AstroSage** / **Cosmic Insights**（网页/App，新手友好）

⚠️ 印度占星需要精确的行星黄经度数。Agent 没有星历表，**无法自行排盘**。请务必使用排盘软件。

用户可保存到项目目录并告知文件名，或直接粘贴星盘文本。排盘应包含：上升度数+星座、Ayanamsa、各行星黄经度数+星座+Nakshatra+Pada、D-1 盘面、Dasha 起止日期。有 D-9 时一并提供。

### 方式二：只给出生时间（不进入正式分析）

```
出生时间: YYYY-MM-DD HH:MM
出生地点: 省-市 (经纬度如有)
性别: 男/女
```
Agent 不估算行星位置。请先用专业软件生成星盘后再分析。

## 数据门槛

- **正式分析**：恒星黄道盘、明确 Ayanamsa、上升和七颗传统行星的精确度数、D-1。
- **Chara Karaka**：必须有每颗行星在本星座内的度分；默认七 Karaka 制（不含 Rahu/Ketu）。若用户指定八 Karaka 制，先说明这是两种不同口径再分析。
- **婚姻或成熟度验证**：需要 D-9。
- **时间分析**：需要软件给出的 Vimshottari Mahadasha/Antardasha 起止日期。
- **Shadbala**：只有用户数据明确提供六力或总分时才作定量判断；不得由模型补算。
- **缺盘直接跳过**，不用估算。

## 数据异常处理

- **缺精确出生分钟且无已排星盘**：不估算上升、宫位和 Dasha，停止正式分析。
- **缺出生地点且无已排星盘**：不使用首都或默认地点代替，请用户补充。
- **Charakaraka 计算时两星度数极为接近（<0°30′）**：标注"AK/AmK 边界模糊，两者皆需参考"，不自行发明并列规则。
- **Dasha 起算**：起始大运由出生星宿+月亮已走度数决定。度数不精确时标注不确定性。

## 固定口径

**七 Karaka 制**（默认）：七颗传统实体行星（日月水金火木土）按各自星座内度数从高到低排列——AK→AmK→BK→MK→PK→GK→DK。八 Karaka 制（含罗睺）为不同传统，仅在用户明确要求时使用，先标注口径差异。

## Decision Cues（用户意图 → 分析重点）

- "看看事业/职业" → 重点：AmK+10宫+10主+相关 Raja Yoga、当前 Dasha 是否触发事业 Yoga
- "婚姻/感情" → 重点：DK+7宫+7主+金星、D-9 中 7 宫状态、当前 Dasha 是否触发婚姻 Yoga
- "财运/赚钱" → 重点：2宫+11宫+财富 Yoga（Dhana Yoga）、木星+金星的宫位和力量
- "灵魂使命/人生课题" → 重点：AK（星座+星宿+宫位+Navamsa）、9宫+木星+Ketu
- "最近运势" → 重点：当前 Mahadasha+Antardasha、土星 Sade Sati（如有）
- "出国/海外发展" → 重点：12宫+Rahu-Ketu 轴线+9宫、D-9 中 12/9 宫
- "健康" → 重点：Lagnesh 受克+6宫+8宫+火星/土星/罗睺的硬相位

## 输出规则

- 正文必须先给“盘面地图与推导过程”，再进入用户指定维度。依次解释：上升与宫主身份 → 行星尊贵度/受克/Nakshatra → Yoga 成立与破格 → D-1/分盘验证 → Dasha 触发。
- 每个关键结论使用三层链：原始盘面 → 对应解释（Parashara/Jaimini 规则、宫主关系、竞争解释）→ 得出结论（中间机制、条件、反证与边界）。
- 先判宫主身份和盘面承诺，再讨论 Dasha 是否触发；不要把某颗天然吉星的大运自动写成好运。
- Yoga 必须列出：参与行星、宫主身份、关系类型（Kendra/Trikona/其他）、关联方式（合相/互容/Parashari 相位——不使用现代六分相）、尊贵度和破格因素。
- D-9 用作条件修正：Vargottama 指示稳定性（不写"翻倍"），D-1 强 D-9 弱降证据强度。
- 燃烧（Combustion）：Parashara 学派对不同行星给出了各自的燃烧度数范围，非统一 8°30′——当用户数据或软件有具体口径时采用该口径；未声明时标注"燃烧范围存在学派差异"。
- 逆行、相位、功能吉凶采用用户软件或所声明学派口径。
- 现实问题必须由相关宫位、宫主、指示星、分盘（若有）和 Dasha 联合判断。单一行星或宫位只能先解释其机制，不能直接指定行业、关系结果或人生事件。
- 每个结论标注盘面依据、数据质量和证据强度。

## 禁止

- 不混入现代占星的六分相、心理相位或热带黄道数据。
- 不虚构 Shadbala、Nakshatra、Pada、Dasha 或分盘位置。
- 不把灵魂、业力、婚姻和健康象征写成事实判断。
- 不使用"确定""必然"描述未来事件。

## 常见错误（Gotchas —— 从真实失败中沉淀，优先级最高）

1. **AK 算错** — 最常见的错：把罗睺/计都算进去了。AK 只计七颗实体行星（日月水金火木土），取黄经最高者。两星极近（<0°30′）标注"AK 边界模糊，两者皆需参考"。

2. **Dasha 违背三原则** — 一看到"走木星大运"就说好运，不看盘里有没有对应的 Yoga。铁律：Yoga 定承诺 → Dasha 定时机 → 行星力量定大小。没有对应 Yoga，走该大运也产生不了结果。

3. **Yoga 只列名字不给判据** — "形成 Raja Yoga"但没说 Kendra 主和 Trikona 主是谁、怎么关联的。不给判据的 Yoga = 无效结论。

4. **D-1 不经 D-9 验证** — 本命盘好就认为一定好。D-1 的承诺必须在 Navamsa 中确认：Vargottama 加持提升信度，D-1 强 D-9 弱降档。

5. **功能吉凶星判断错误** — 直接背"木星吉星、土星凶星"不看上升。同一行星在不同上升下功能完全不同。必须从实际上升逐宫推导。

6. **Gaja Kesari 从上升起算** — 常见错。Gaja Kesari 需要 Jupiter 在 Moon 的 Kendra（从月亮位置起算 1/4/7/10 宫），不是从上升起算。两者结果可能不同。

7. **现代六分相用于吠陀 Yoga** — Chandra-Mangal Yoga 用六分相检验是错误的。吠陀使用 Parashari 相位系统（graha drishti），不是现代角度相位。

8. **宫位被直接翻译成现实标签** — 同一宫位可在多个领域以不同形式表现。先判断宫主关系、行星状态和中间机制，再比较用户提出的候选解释。

- [ ] 功能吉凶星是否按实际上升逐宫推导（非照搬其他上升示例）？
- [ ] 已列出 Yoga 是否给出了成立的判据（不只是名字）？
- [ ] Dasha 解读是否有"盘中有对应 Yoga 才给结论"的逻辑？
- [ ] Gaja Kesari 是否从月亮 Kendra 起算？
- [ ] 有没有使用现代六分相检验吠陀 Yoga？
- [ ] 现实判断是否联合相关宫位、宫主、指示星和分盘，而不是只看一个落座？
