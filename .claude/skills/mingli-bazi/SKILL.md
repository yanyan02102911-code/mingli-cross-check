# 八字分析

## 开始前

1. 读取用户提供的数据，回显四柱、性别、出生时间地点、换日口径（民用零点/子初换日）、起运和大运状态。
2. 用户未确认前不进入正式分析。
3. 把"用户提供未校验""脚本单项校验""专业软件已核对"分开标注。

## 数据输入方式

### 方式一：排盘软件导出（推荐）

推荐软件：
- **爱占星**（全体系通用，八字/紫微/印占/现代都支持，一个 App 搞定四个盘）
- **测测**（全体系通用，网页版也可用）
- **问真八字**（八字专用，排盘详细、带大运流年）

用户可保存到项目目录并告知文件名，或直接粘贴排盘文本。排盘文本中包含「年柱/月柱/日柱/时柱」「大运」「起运」等关键信息。

### 方式二：直接给四柱

不需要懂专业术语。给四柱天干地支就行：
```
年柱: 甲子
月柱: 丙寅
日柱: 戊辰
时柱: 庚申
性别: 男
```
给不全四柱也可以——缺的标注清楚，分析时标明限制。

### 方式三：只给出生时间（精度不如软件排盘）

```
出生时间: YYYY-MM-DD HH:MM
出生地点: 省-市
性别: 男/女
```
Skill 会用 `calculate-day-pillar.mjs` 校验日柱，标注"自动排盘未校验"。节气月柱、真太阳时、起运岁数不做自动计算——需用户提供软件排盘结果。

## 数据门槛

- **正式原局分析**：至少需要年、月、日、时四柱。缺时柱时只分析前三柱，排除时柱相关主题（子女、晚景、精确应期）。
- **大运/流年分析**：必须有性别、起运年龄、顺逆和大运列表。缺少任一项时只做原局结构性分析，不输出具体年份窗口。起运可用 `calculate-big-luck.mjs` 辅助计算。
- **仅出生日期**：只校验日柱，标注"自动排盘未校验"。不得声称已完成完整排盘。
- **节气边界、23时换日、地点时差**：会改变盘面时暂停，请求用户确认口径。

## 数据异常处理

- **缺出生时辰**：只分析前三柱（年月日），不以任何时辰作为默认值。时柱、子女、晚景和精确应期不输出。
- **缺出生地点**：不做真太阳时边界判断，标注「未经地理校正」。
- **缺性别**：必须询问，不可猜测。性别决定大运顺逆排方向。
- **排盘不确定**：标注「待确认」而非强行判断。起运年龄有差异时标注两种算法结果。

## 路由

- 快速问题：读取 [references/workflow-standard.md](references/workflow-standard.md)，只回答用户指定维度。
- 标准报告：读取同一文件，覆盖核心结构、指定维度、限制和可用时间数据。
- 深度报告：再读取 [references/workflow-deep.md](references/workflow-deep.md)，分开呈现子平与盲派推理。

## Decision Cues（用户意图 → 分析重点）

当用户说以下内容时，调整分析权重，不要十个维度平均用力：

- "看看事业/工作/职业" → 重点：官杀+印星+财星组合、盲派做功方式判定、大运走势
- "婚姻/感情" → 重点：日支夫妻宫+官杀星+日主合官/合财、盲派宾主合关系
- "财运/赚钱" → 重点：财星+食伤生财+财库+盲派墓用结构
- "健康/身体" → 重点：日主强弱+五行偏枯+冲克日主的大运
- "适合做什么/天赋" → 重点：格局判定+功神类型（制用→竞争/合用→合作/生用→创造）
- "今年/明年运势" → 重点：当前大运+流年与原局的刑冲合害触发
- "跟父母/家里关系" → 重点：年月柱+印星+财星制印
- "性格/我是什么样的人" → 重点：日主+月令+十神组合+日支特性

## 输出规则

- 正文必须先给“盘面地图与推导过程”，再进入用户指定维度。依次解释：四柱/藏干/十神 → 旺衰四步 → 格局及成败条件 → 干支作用与盲派做功 → 喜忌；只解释本盘实际用到的知识。
- 每个关键结论使用三层链：原始盘面 → 对应解释（规则、作用关系、竞争解释）→ 得出结论（中间机制、条件、反证与边界）。
- 每个关键判断写明：结论、学派来源、盘面依据、现实表现、反例或限制、数据状态、证据强度（强/中/弱）。
- 旺衰、格局、调候是不同判断层，不用一个结论替代其他层。旺衰看日主承担力，格局看社会角色，调候看环境适配。
- 盲派结构必须指出具体刑冲合害穿墓或干支作用；找不到就写"无明显做功结构"。
- 神煞和纳音只作辅助，不单独承担关键结论。只列真正起作用的——能跟子平或盲派结论形成交叉验证的才写。
- 子平与盲派冲突时并列呈现：明确标出「子平认为___，盲派认为___」→ 分析原因（时间尺度不同/角度差异/方法论边界）→ 给出采纳建议，不强行调和。
- 回答任何现实选择题时，先把选项拆成可观察的条件，再由全局结构分别寻找支持与反证；任何单项都不能直接等同某个现实标签。
- **不把预测写成事实**：禁止用「确定」描述未来事件。医疗、投资、法律等内容只作学习参考。

## 禁止

- 不引入其他命理体系（紫微、印占、现代占星）。
- 不输出没有大运数据支持的婚期、职业转折或具体年份。
- 不把"身旺/身弱"直接等同于好坏、财富或社会层级。
- 不把“食神制杀”“禄头带财”“将星”“自刑”等单一结构直接翻译为具体职业、重大事件或固定财富等级。
- 不把健康象征写成诊断（如"官杀旺=心脏病"）。
- 不使用"确定""必然""一定"描述未来事件。
- 不跳过排盘校验直接分析。

## 常见错误（Gotchas —— 从真实失败中沉淀，优先级最高）

1. **旺衰走极端** — 大部分人不是身强从弱，而是中和偏强/偏弱。见禄见印就说身旺、见官杀就说身弱 → 最常见诊断错。正确：按旺衰四步逐条判，四步取交集。

2. **格局取错优先级** — 直接按月令本气取格，忽略透干优先和"官杀为先"。官杀透干时即使月令是财印也必须先论官杀格。"有杀先论杀，无杀方论用"是子平铁律。

3. **盲派功神全靠猜** — 没从命盘找刑冲克穿合墓的证据就说"做功不错"。正确：逐条检查日干合→日支刑冲克穿合墓→禄做功，三条都没找到就说"无明显做功结构"。

4. **纳音神煞堆砌** — 全盘所有纳音和神煞都列出来但不跟结论挂钩。正确：只列真正起作用的——能跟子平或盲派结论形成交叉验证的才写。不堆砌。

5. **子平盲派冲突被掩盖** — 两派结论不同就强行折中。正确：明确标出分歧 + 分析原因（时间尺度/角度差异/方法论边界）+ 给出采纳建议。

6. **调候被忽略** — 冬夏两季出生的命局，调候跟格局同等重要。如冬月金水伤官格，虽格成但无火调候则格局层次大降。旺衰和格局判断完成后必须检查调候。

7. **合化条件不验证** — 看到天干五合就说"合化成功"。合化成立需要严格条件：化神在月令当令、双方有根、无克破。条件不全是"合而不化"。"合而不化"和"合化成功"结论完全不同。

8. **现实结论跨层跳跃** — “见到某十神/口诀→直接对应某个现实选项”属于跳步。先解释该结构反映的机制，再与全局反证、时间承载力和问题条件组合判断。

## 质量自检

分析完成后逐条自检：
- [ ] 排盘来源和完整度是否标注清楚？
- [ ] 旺衰判断每一步都有明确盘面依据？四步取交集而非单步定论？
- [ ] 格局是否按"透干优先、官杀为先"取格？相神是否找了？
- [ ] 盲派功神是从命盘找出来的，不是猜的？
- [ ] 调候需求是否检查了（尤其冬夏出生）？
- [ ] 纳音神煞只列了起作用的，而非全盘堆砌？
- [ ] 子平盲派冲突是标出来了还是被掩盖了？
- [ ] 合化条件是否验证了？"合而不化"还是"合化成功"？
- [ ] 现实结论是否经过盘面事实、作用关系和中间判断？是否列出至少一个竞争解释？
- [ ] 有没有引入八字体系外的术语？
- [ ] 有没有用"确定""必然"描述未来事件？
